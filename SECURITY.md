# Security Policy

## Supported Versions

LinkForge provides active security updates and vulnerability patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

We take the security of LinkForge very seriously. If you believe you have found a security vulnerability in this repository, please follow these disclosure guidelines:

### 1. Do NOT open a public GitHub issue
Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

### 2. Private Vulnerability Reporting
Please submit a private security vulnerability report via **GitHub Security Advisories**:
- Go to the **Security** tab of the repository
- Click **Report a vulnerability** to open an advisory draft

Alternatively, if private reporting is unavailable, reach out directly to the maintainer via the profile contact options listed on GitHub.

### 3. Information to Include
When reporting, please provide the following details:
- A clear description of the vulnerability and its potential impact
- Detailed reproduction steps, including code samples, HTTP request traces, or a proof of concept (PoC)
- Any proposed remediations or patches

### 4. Response Timeline
- We will acknowledge receipt of your vulnerability report within **48 hours**.
- We will evaluate and provide a timeline for validation and remediation within **7 business days**.
- Once patched, we will publish a security advisory and credit the reporter (unless you request anonymity).
